# JP Carpenter mark

**Brief:** Calm reviewer's stamp for a Security and Compliance Analyst who checks signed claims against running systems.

**Type:** Symbol + lockup (wordmark).

**One-color:** Uses `currentColor` in `mark.svg` / `lockup.svg`. Favicon is the Soft Block face (outlined Atkinson Bold JP + amber rule) with a thin plate margin so it reads on a white tab.

## Don't

- Shield, padlock, swoosh, circuit board, AI sparkle
- Gradients, drop shadows, bevels
- Stretching, rotating past 0°, enclosing in a second shape
- Recoloring the stamp pip separately from the rail (one ink)

## Min size

- Mark alone: 16×16 (favicon)
- Lockup: 120px wide before dropping to mark-only

## Grounds

| Ground | Ink |
|--------|-----|
| Bone field | Sage `#64705b` |
| Wood plate | Bone `#ebe6dc` or sage wash `#a8b39a` |
| CRT / near-black | Trace sage `#a8b39a` |
