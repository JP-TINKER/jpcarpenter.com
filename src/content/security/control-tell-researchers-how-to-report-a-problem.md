**In plain terms:** if someone finds a real issue with this website,
              they should know who to email, without hunting through contact pages.
            

**Why it matters here:** disclosure channels are basic operational
              hygiene. On a small static site the risk surface is small, but the courtesy still
              matters.
            

**How:**
              [/.well-known/security.txt](/.well-known/security.txt) points to
              [jp@jpcarpenter.com](mailto:jp@jpcarpenter.com) and links back here.
            

**Sources**

- [RFC 9116, A File Format to Aid in Security Vulnerability Disclosure (security.txt)](https://www.rfc-editor.org/rfc/rfc9116)
