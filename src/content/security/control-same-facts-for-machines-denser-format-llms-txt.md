**In plain terms:** there is a plain-text summary at
              [/llms.txt](/llms.txt) written for automated readers. It packs the same
              biography, work claims, and lab findings into a structure machines parse easily.
            

**Why it matters here:** giving bots a denser copy of the truth is not
              the same as showing them a *different* story. Cloaking (one page for humans,
              another for bots) is dishonest and gets sites penalized. One truth, two formats.
            

**How:** `llms.txt` is a public file. It is not in the
              primary navigation so humans are not pushed through it. Anyone who opens the URL
              sees the same text a bot would. Evidence that `llms.txt` moves rankings
              on personal sites is weak; keep it as housekeeping, not a growth lever.
            

**Sources**

- Emerging `llms.txt` convention for structured site summaries for LLM /
                agent readers (paired here with honest robots policy, not as a substitute for it).
              
- This site's rule: no cloaking, documented on this page and in `llms.txt`.
